# Carbon Footprint Tracker

A lightweight HTML + CSS + JavaScript website for tracking daily transportation, food, shopping, and other emissions using localStorage.

## Project structure

```text
carbon-footprint-tracker/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── app.js
│   ├── data.js
│   └── storage.js
├── README.md
└── .gitignore
```

## Features

- Landing page and auth flow
- Dashboard with total footprint and category breakdown
- Activity tracking for transport, food, shopping, and other categories
- LocalStorage persistence
- History view with time filters
- Progress overview and goals
- Personalized low-carbon recommendations
- Mobile-friendly bottom navigation

## Run locally

1. Open the project folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html` and choose Open with Live Server.

## Notes

- This is a frontend/localStorage prototype for a college or project website.
- Emission values are approximate and based on the brief and reference factors provided for the MVP.
- The app uses `Estimated CO₂e` language rather than claiming exact scientific measurement.
